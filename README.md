# Космослов

Українська енциклопедія світу фантастики з науково-фантастичним ядром та
дослідницький полігон Exometric, Manifold OS, Клубка і локального AutoResearch.
Корпус відкритий до тисяч і десятків тисяч творів: 5000 — початковий орієнтир,
а не межа. Черговість визначатиметься документованим внеском авторів і творів.

## Поточний реалізований стан

Чинний аудит: **Great Attractor (ШІ) + користувач (людина)**.
[Перші 10 змістових рекомендацій для рішення аудитора](docs/GREAT_ATTRACTOR_REVIEW_V1.md).
Це відкритий аудит, не незалежне оцінювання двома людьми.

Перший етап: дослідницькі картки «термін у конкретному творі» з окремими
корпусними засвідченнями та українськими пропозиціями. Картки є чернетками.
Визначення, бібліографія та переклади ще потребують редакторської перевірки.

Після партії 2026-09-07: 233 картки, 229 засвідчень повторно перевірено
за байтами й картою зон, 47 українських пропозицій. Виконано 69 фрагментів
з 1015 у незмінному модельному профілі. Це датований результат,
не автоматично актуальна статистика й не доказ історичної першості термінів.

## Відтворюваний експорт

[Перевірка редакторських форм і узгодженість оцінювачів](docs/IMPLEMENTATION_STEP_10.md).

Поточне обмеження деривації та критична звірка аудиту:
[крок 09](docs/IMPLEMENTATION_STEP_09.md). Готові редакторські форми
описано в [процедурі](docs/EDITORIAL_REVIEW_RUNBOOK_V1.md); оцінювання ще не виконано.

```powershell
python scripts/run_evidence_export.py
python -m pytest -q tests/test_evidence_export.py test_zones_witness.py
```

Скрипт створює окремий каталог `.benchmarks/evidence-export-<UTC>/`:
копію SQLite, Markdown, JSON і квитанцію з хешами виконавця та результатів.
Працює на копії, робочі записи не змінює. Для цитат потрібні оригінальні
файли та `zones.json` за шляхами з бази. Недоступна або змінена цитата
потрапляє у звіт як відмова без публікації її тексту.

Квитанція початкового експорту містить звичайні SHA-256. Наступний
[етап Exometric](docs/IMPLEMENTATION_STEP_02.md) вже запечатав пакет із
63 артефактів і перевірив його незалежним кодом Manifold. Окремий
[anchor аудитора](docs/audit_anchors/step02-001.json) збережено локально;
якорі також передано в GitHub. Незалежний людський аудит ще не підтверджений.

## Наявний прототип

`core/` — SQLite та попередні моделі; `modules/corpus/` — корпус і засвідчення;
`modules/lexicography/` — словникові джерела та експорт;
`modules/autoresearch/` — локальний дослідний цикл;
`app.py` — Streamlit; `cli.py` — командний інтерфейс.

Попередні інтерфейси та AutoResearch ще не приведені повністю до контракту v1.
Фіксована формула Cult Index залишається евристикою прототипу. Вона не є
валідацією внеску твору. Приклади зі старих seed-даних і неперевірені
посилання на Грінченка не слід використовувати як наукові докази.
