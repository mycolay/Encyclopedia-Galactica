# 🌌 «Космослов» (AutoSciFi & Lexicon)
### Науково-дослідна система дослідження культової світової фантастики (1000+ творів), корпусу текстів мовою оригіналу та Словника науково-фантастичних неологізмів на основі моделей Словника Бориса Грінченка

---

## 📌 Наукова мета та філософія проєкту

Наукова фантастика (Science Fiction) — це не просто белетристика, а лабораторія конструювання майбутнього. Саме в надрах фантастичних творів народжуються поняття, технології та соціологічні концепції за десятиліття до їхньої появи в реальності.

Цей проєкт ставить за мету вирішити три фундаментальні академічні проблеми:
1. **Об'єктивізація культовості**: побудова інтегрального рейтингу культовості (**Cult Index**) для понад 1000 творів та їхніх авторів на основі нагород (Hugo, Nebula, Locus, Clarke, BSFA, Campbell, Philip K. Dick), канонічних списків (SF Masterworks, NPR Top 100) та репутаційного консенсусу світової спільноти поціновувачів (r/printSF, ISFDB).
2. **Академічна текстологія та корпус**: створення цифрового середовища для збереження повних текстів мовою оригіналу автора (англійська, польська, чеська, французька тощо) з повнотекстовою індексацією для точної фіксації першої появи термінів (**First Attestation**).
3. **Органічна українська термінографія за Грінченком**: творчий та науково вивірений переклад неологізмів. Замість бездумної транслітерації чи механічних кальок система спирається на глибинну морфологічну структуру української мови, зафіксовану в 4-томному «Словарі української мови» за ред. Бориса Грінченка (1907–1909), відроджуючи автентичні префікси, суфікси та моделі складних композитів.
4. **Автономний агент дослідження (AutoResearch / The Karpathy Loop)**: втілення принципу замкненого дослідницького циклу Андрія Карпатого (*Propose ➔ Execute ➔ Synthesize ➔ Evaluate ➔ Commit/Rollback*) за допомогою локальних LLM (**Qwen 3.6:35b** / **Qwen 3.5:27b**) на відеокарті **NVIDIA GeForce RTX 3090 (24 GB VRAM)**.

## 🧮 Формула Культового Індексу (Cult Index)

$$\text{CultIndex} = \min\left(99.8, \left(40 + S_{\text{awards}} + S_{\text{canon}} + S_{\text{trope}}\right) \times M_{\text{era}} \times 0.72\right)$$

* **$S_{\text{awards}}$**: Нагороди (Hugo Win = +12, Nebula Win = +11, Locus Win = +9, Clarke = +9, PKD = +8, BSFA = +7 тощо).
* **$S_{\text{canon}}$**: Канонічні антології (SF Masterworks = +18, Locus All-Time = +16, NPR Top 100 = +14, r/printSF = +12).
* **$S_{\text{trope}}$**: Винахідник парадигми / жанроутворюючий твір (+15).
* **$M_{\text{era}}$**: Історичний коефіцієнт (для класиків епохи до запровадження премій: Верн, Веллс, Чапек, Шеллі), що гарантує збереження їхнього титанічного статусу.

## 🚀 Як запускати систему

### 1. Ініціалізація бази даних та корпусу
```bash
python init_system.py
```

### 2. Запуск інтерактивного веб-дашборду (Streamlit)
```bash
python -m streamlit run app.py
```
Відкриється браузер за адресою `http://localhost:8501`, де доступні:
* Рейтинг культових творів та авторів з фільтрацією;
* Інтерактивний Словник неологізмів з повнотекстовим пошуком;
* Читальний зал оригінальних текстів корпусу;
* Пульт управління AutoResearch з моніторингом RTX 3090 у реальному часі;
* Компас словотвору за словником Грінченка.

### 3. Запуск через Rich CLI (Термінал)
```bash
# Перегляд статистики
python cli.py stats

# Перегляд вершини каталогу
python cli.py catalog

# Пошук у Словнику
python cli.py dictionary --search ansible

# Запуск одного циклу Karpathy Loop
python cli.py run-cycle --model qwen3.5:27b

# Експорт академічного звіту
python cli.py export
```

### 4. Автоматизоване тестування
```bash
python -m pytest -v test_system.py
```
