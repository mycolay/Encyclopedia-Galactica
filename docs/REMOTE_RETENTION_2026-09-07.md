Репозиторій: https://github.com/mycolay/Encyclopedia-Galactica

На запит власника підключено origin і виконано перший push у main.
GitHub підтвердив refs/heads/main:
`a61dedb2c1a9c82c2f6a171c82f68cfd4691efdf`.
Це історія проєкту включно з кодом, поточною базою, дослідницьким
експортом і контрольними якорями кроків 02, 04 та 05.
Локальну назву робочої гілки збережено; її upstream — origin/main.
Для наступного відправлення використовується `git push origin HEAD:main`.

Повні незмінні пакети прогонів у .benchmarks не входять до Git.
Вони збережені окремо на NAS; шляхи та результати перевірки наведено
у звітах відповідних кроків. Відновлення потребує і Git-історії,
і пакета прогону з NAS. Публічний код сам по собі не забезпечує доступу
до корпусу за локальними шляхами.

Зберігання якорів більше не обмежується одним диском. GitHub є зовнішньою
копією історії, але push не є незалежним людським аудитом, довіреною
часовою позначкою чи незмінним архівом. Поля про очікуваний людський
аудит у старих запечатаних пакетах не переписуються.
