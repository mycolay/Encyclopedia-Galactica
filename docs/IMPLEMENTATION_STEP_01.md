# Крок 01 — експорт доказових дослідницьких карток

Дата: 2026-09-06. Статус: реалізовано й перевірено в локальному прогоні;
наукова валідація статей не заявляється.

## Проблема та рішення

Старий експорт читав 6 записів terms і застарілий JSON словотвору,
ігноруючи окремі засвідчення без term_id. Він виводив None замість цитат,
непідтверджені формулювання першості та мав обмеження у 1000 термінів.

Новий експорт об'єднує записи для конкретної назви й конкретного твору,
включає засвідчення без term_id та бере пропозиції з актуального реєстру.
Читає всі записи в одній read-only транзакції; схему робочої бази не змінює.
Перевіряє цитати перед публікацією. Застарілі вільні цитати та старий JSON
неологізмів не використовуються як доказ. Визначення збережено з явною
позначкою редакторської неперевіреності.

## Прогін

Команда: `python scripts/run_evidence_export.py`.

Артефакти: `.benchmarks/evidence-export-20260906T213919649864Z/`.
Там збережено snapshot.db, Markdown, JSON, receipt.json з хешами.
Markdown та JSON перенесені до docs без редагування.

Результат: 88 карток; 84/84 засвідчення пройшли повторну перевірку;
15 українських пропозицій; відмов 0. Кількість карток не дорівнює кількості
унікальних понять: поняття й значення ще не виділено окремою міграцією.

Тести: `python -m pytest -q tests/test_evidence_export.py test_zones_witness.py`:
10 passed. Перевірено підміну тексту, чужий термін із правильною matched_form,
перетин меж зони, відсутню карту, понад 1000 карток, засвідчення без term_id,
розділення пропозицій і фактів та незмінність тестової БД після експорту.
Перше виконання мало одну невдалу тестову вимогу: укорочена підміна давала
short_read раніше за artifact_drift. Фікстуру змінено на підміну тієї самої
довжини; обидва випадки означають відмову в публікації цитати.

## Межі та наступний крок

Перевірка хешу карти засвідчує її прив'язку до тексту, не правильність
текстологічної сегментації. Дати й визначення цим прогоном не валідовано.
Словникові обґрунтування потребують окремого повторного верифікатора.
Виправлення стосується експорту; Streamlit і старий AutoResearch потребують
окремого оновлення. Великі експортні набори ще не профільовано за пам'яттю.

Це звичайна квитанція з хешами, не Exometric seal. Наступний крок — адаптер
Exometric з незалежною перевіркою й відокремленим head для аудитора.

Повторний прогін після усунення кінцевих пробілів у Markdown дав ті самі
лічильники; точні пробіли цитат збережено в JSON. Попередній прогін
20260906T213732841728Z залишено в .benchmarks для історії.
