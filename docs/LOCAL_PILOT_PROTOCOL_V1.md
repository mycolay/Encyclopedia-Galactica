# Локальний пілот — один фрагмент, v1

Дата плану: 2026-09-07. Протокол і виконавець фіксуються комітом до
першого модельного запиту. Повторне виконання цього самого пакета заборонене.

## Предмет і бюджет

Твір: work_id=15, H.G. Wells, The Time Machine. Беремо перший фрагмент
першої body-зони за чинним планувальником: 8000 символів, перекриття 200.
Межі й джерело копіюються до пакета до запиту. Вибір не залежить від
відповіді моделі. Це перевірка конвеєра, не оцінка точності на вибірці.

Модель: qwen3.5:27b, локальний digest
`7653528ba5cba4dd8e19da24aaddc7f4d0b5ecd93571c0825dfd4137958ec06e`.
Один POST generate, num_ctx=8192, num_predict=512, temperature=0.2,
top_p=0.9, seed=7, think=false, keep_alive=0. Таймаути connect=5 с,
read=180 с. Точний запит зберігається до виконання. Повторів немає.
Seed не гарантує побітового повторення inference на іншому обладнанні.

Доступ: лише localhost:11434; без платних API, завантаження моделей і
змін сторонніх воркерів. Перед стартом Ollama не має завантажених моделей,
GPU memory.used <=6000 MiB, utilization <=20%. Локальний lock виключає
паралельні запуски цього пілота; він не є загальним lock інших проєктів.
Digest тегу перевіряється до та після generation. keep_alive=0 просить
сервер вивантажити модель після відповіді; postflight перевіряє стан.

## Передбачення і критерії

Очікується завершена JSON-відповідь candidates:list[str]. Які саме
терміни будуть запропоновані, не задаємо. Валідний порожній список є
результатом. done_reason=length, невалідний JSON, дрейф моделі/тексту,
timeout — помилка без зарахування покриття; вихід і помилка зберігаються.
Thinking не підставляється замість фінальної відповіді; JSON не ремонтується.

Кандидати перевіряються детермінованим пошуком у реально переданому
фрагменті. Координати відносні до оригінального UTF-8 файла. Наявність
словосполучення не підтверджує його фантастичний статус, семантику або
історичну першість. В основні terms/attestations цей прогін нічого не пише.

Вимірюємо wall time, серверні total/load/prompt_eval/eval duration,
prompt_eval_count та eval_count. Тривалості сервера — наносекунди;
eval_count / (eval_duration/1e9) — швидкість генерації, не наскрізна
пропускна здатність. Енергоспоживання й GPU-секунди не вимірюються.

## Артефакти та аудит

Окрема queue.db, прогрес до й після, оригінал і zones, точний запит,
сирі байти відповіді, JSON, метрики, локалізації, код і протокол.
Пакет запечатується наявними Exometric/Manifold, незалежно перевіряється;
anchor зберігається окремим Git-комітом. Помилковий модельний результат
також може мати коректну печатку цілісності. Нуль кандидатів не є відмовою
інфраструктури, а наявність кандидатів не є науковою валідацією.

Виконавець: scripts/run_local_pilot.py. Тести використовують HTTP-фікстури,
перевіряють бюджет, точні параметри, запис метрик, відмову на обрізаній
відповіді, невалідному JSON і timeout.

API та одиниці метрик звірені з офіційним описом:
https://docs.ollama.com/api/generate
