# Контракт дослідницької картки v1

Перший реалізований зріз майбутньої енциклопедичної статті — назва терміна
в конкретному творі. Ключ: нормалізована назва + work_id. Це не ідентичність
поняття: автоматичне об'єднання однакових назв між творами заборонене.

JSON: `cosmoslov.research_cards.v1`; поля term, work_id, title, author,
work_year, definition, traditional, attestations, proposals, external,
earliest_in_work_corpus. Визначення й традиційні відповідники зі старих
даних мають статус неперевірених у цьому експорті. Старий JSON неологізмів
не використовується: джерело пропозицій — актуальний реєстр attestations.

Засвідчення не потребує term_id: окремі записи без старої статті також
потрапляють у картки. Цитата публікується лише після перевірки SHA-256
артефакту, координат, хешу вікна, UTF-8, терміна та повного включення
в зону body карти з відповідним source_sha256. Невдала перевірка залишає
запис із причиною відмови, без цитати. Перевірка карти не встановлює
текстологічну правильність її меж; це окремий аудит.

Українська пропозиція не стає затвердженою через наявність verified_at_utc
чи root_attested_in_grinchenko. Словникові посилання потребують власного
верифікатора; цей експорт чесно вказує, що їх повторно не перевіряв.

Дата засвідчення береться з метаданих. Мінімум обчислюється тільки серед
успішно перевірених записів конкретного твору. Це не доказ історичної першості.

Наступна міграція має додати поняття, значення, видання, джерела перекладів,
редакторські рішення й їх історію. Поточний крок не змінює схему робочої БД.
