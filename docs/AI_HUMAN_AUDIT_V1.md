# Чинна схема: Great Attractor і людський аудитор

За уточненням користувача Great Attractor — ім'я ШІ-оркестранта,
другий учасник — користувач, людський аудитор. Це замінює вимогу
двох людей для поточного робочого процесу. Старі незмінні пакети
залишаються історією попереднього дизайну.

Great Attractor читає оригінал, пропонує категорію, відповідник,
оцінки та аргументи, явно показує невизначеність. Аудитор приймає,
виправляє, відхиляє або відкладає кожне рішення. Його порожні поля
не заповнюються асистентом і не означають згоди. Оцінки ШІ не є
незалежною людською експертизою, а експозиція пропозицій робить аудит відкритим.

Порівняння відповідей можливе як діагностика розбіжностей, але
Cohen kappa для цієї схеми не публікується як міжекспертна узгодженість.
Код явно розрізняє role=ai та role=human. Режим двох людей залишається
окремою майбутньою можливістю; його не використовують для поточного аудиту.

Чинний gate деривації зберігається: лише людське контекстне include-рішення
дає допуск. ШІ-пропозиція include — рекомендація, не дозвіл і не
затвердження статті. Доречність, якість перекладу та статус публікації —
окремі рішення. Хороший переклад загального слова не робить його НФ-терміном.

Спочатку використовуємо десять наявних калібрувальних прикладів як навчальний
відкритий аудит. Для записів без достатнього джерела — NA з поясненням.
Неперевірені словникові посилання залишаються неперевіреними навіть за
наявності правдоподібного словотвору. Чеські та англійські уривки можуть
потребувати додаткової мовної експертизи за рішенням аудитора.
