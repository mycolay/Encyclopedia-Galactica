байти перевірені за квитанцією експорту та включені в пакет.

Вхід: `.benchmarks/evidence-export-20260906T213919649864Z/`.

23 картами зон, snapshot.db, результатами експорту та файлами виконавців.
Загальний розмір каталогу з діагностикою: 8 587 147 байтів.

підтверджена для 63 артефактів; imports_exometric=false.
Широкий ініціалізатор пакета Orcestr не завантажувався.

Тести: 17 пройшли (7 нових Exometric + 10 попередніх). Після додавання
файлів протоколу до складу пакета повторно пройшли 7 відповідних тестів.
Чистий і перенесений пакети приймаються; підміна вмісту, перестановка
маніфесту, самосумісне обрізання, неправильний anchor, підміна незалежного
перевіряльника, вихід шляху за каталог і перезапис пакета відхиляються.

Не використовувалися мережа, LLM або GPU. Робоча БД, оригінали корпусу,
попередні прогони та сусідні репозиторії не змінювалися.

## Інструкція аудитору

Збережи файл step02-001.json у власному незалежному сховищі. Поточна копія
в Git є локальним записом виконавця; зовнішнє збереження ще не підтверджене.
Не замінюй збережений anchor новою копією з пакета, який перевіряєш.

Із кореня проєкту:

```powershell
python scripts/audit_export.py verify --bundle .benchmarks/sealed-export-step02-001 --anchor docs/audit_anchors/step02-001.json
```

Для власного аудиту передай у --anchor шлях до своєї збереженої копії.
Очікується exit code 0, verdict PASS, artifact_count 63 і head:

`b3ddcbcd13eb716cc550c84a3e1939d481bdc8899d4059f24e22e2e2fe0721aa`

SHA-256 manifest:

`0745cc069f7c767e45a3c6521ffe117824e9446e3502f6aa425eca4127c9bdd1`

Це PASS цілісності, не наукової якості. Локальний час не є довіреною
часовою позначкою. Для перевірки перенесеного пакета диск K: не потрібний;
для повторного запуску старого експорту треба окремо переналаштувати шляхи
у копії snapshot.db. Оригінальний snapshot лишається незмінним.
